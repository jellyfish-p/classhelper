# 课堂助手产品范围

> 状态：已确认
> 更新日期：2026-08-08

## 产品定位

课堂助手是安装在中小学教室固定电脑上的 Windows 桌面工具，专注于固定名单和课堂随机点名。课程表、节假日、教学日历与桌面课程栏由 ClassIsland 承担，不在本项目范围内。

软件跟随教室电脑，而不是跟随教师或学生。首版没有学生客户端、应用内账号、云同步或复杂权限体系。

## 支持环境

- 64 位 Windows 10/11；
- 普通教室电脑，最低按 4 GB 内存环境验证；
- 允许断网使用全部核心功能；
- 不支持 Windows 7/8、Linux 或 macOS。

## 用户界面

### 快捷启动器

- 始终位于普通窗口上方；
- 可以拖动，并自动吸附当前屏幕边缘；
- 提供随机点名、固定名单和主控面板入口；
- 记住位置，并在屏幕变化后回到可见区域；
- 不显示课程、日期或节假日信息。

### 主控面板

主控面板是普通 Windows 窗口，集中管理：

- 固定名单及导入；
- 点名方式；
- 快捷启动器与开机自启；
- 软件更新和关于信息。

### 随机点名窗口

- 从快捷启动器打开独立窗口展示结果；
- 教师可以选择独立随机或均衡轮选；
- 独立随机每次使用完整名单，允许连续抽中同一人；
- 均衡轮选在一轮内不重复，全部抽完后开启新一轮；
- 允许手动重置当前轮次。

首版不保存长期点名历史；均衡轮选状态只在当前点名会话内有效。

## 固定名单

- 一套安装只维护一份固定名单；
- 姓名必填，学号或座号可选；
- 支持逐行新增、删除、修改和暂停参与点名；
- 支持从 Excel 复制后直接粘贴；
- 后续支持导入 `.xlsx` 和 `.csv`；
- 不收集成绩、性别等与点名无关的信息。

## 数据与隐私

- 固定名单最终属于教室，在同一电脑的 Windows 用户之间共享；
- 快捷启动器位置、开机自启和界面偏好属于当前 Windows 用户；
- 首版预览使用当前用户目录下的本地 JSON，后续迁移为整机共享 SQLite；
- 不提供云同步，不上传名单、点名结果、设备标识或使用统计；
- 不接入第三方分析或遥测 SDK。

## 可选开机自启

- 每个 Windows 用户独立选择是否自启；
- 安装后默认不开启；
- 自启时只显示贴边启动器，不自动打开主控面板。

## 明确不做

- 课程表、节次、单双周或三周循环；
- 顶部桌面课程栏、节假日和教学日历；
- ClassIsland 已覆盖的课程展示能力；
- 学生端、教师账号、登录与角色权限；
- 云同步、远程控制、Web 后台；
- 成绩或学生档案管理；
- 遥测、广告和第三方分析。
