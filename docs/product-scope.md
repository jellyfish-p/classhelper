# 课堂助手产品范围

> 状态：已确认  
> 日期：2026-08-08

## 产品定位

课堂助手是安装在中小学教室固定电脑上的 Windows 桌面软件。它在不打断授课的前提下展示当天课程，并提供教学日历、固定名单随机点名和集中设置能力。

软件跟随教室电脑，而不是跟随教师或学生。首版没有学生客户端、应用内账号、云同步或复杂权限体系。

## 支持环境

- 64 位 Windows 11，以及仍处于 Microsoft 生命周期或 ESU 支持中的 Windows 10（重点验证 Windows 10 Enterprise LTSC 2021 与 22H2）。
- 已退出系统支持且未加入 ESU 的 Windows 10 可以尽力兼容，但不承诺完整支持。
- 普通教室电脑，最低按 4 GB 内存环境验证。
- 允许断网使用全部核心功能。
- 不支持 Windows 7/8，不保留 Linux 兼容约束。

## 用户界面

### 顶部课程表

- 贴在桌面顶部并处于普通窗口下方。
- 不抢键盘焦点，不出现在任务栏和 Alt+Tab 列表中。
- 只显示当天全部节次，突出当前课程和下一节课，并显示当前课表周期位置。
- 完整课表的查看与编辑由主控面板承担。

### 快捷启动器

- 始终位于普通窗口上方。
- 可以拖动，并自动吸附当前屏幕边缘。
- 记住所属屏幕、吸附边缘与偏移位置；屏幕失效后必须回到可见区域。
- 首版只启动课程表、教学日历、随机点名和设置等内部功能。
- 外部程序、文件、文件夹和网址快捷项不在首版范围内。

### 主控面板

主控面板是普通 Windows 窗口，集中管理：

- 完整课程表与周期设置；
- 节次和上下课时间；
- 教学日历与法定日历建议；
- 固定名单及导入；
- 点名默认模式；
- 显示屏、窗口位置、开机自启和更新设置。

### 随机点名窗口

- 从快捷启动器打开独立窗口展示结果。
- 教师可以选择独立随机或均衡轮选。
- 独立随机每次使用完整名单，允许连续抽中同一人。
- 均衡轮选在一轮内不重复，全部抽完后开启新一轮；允许手动重置和临时排除缺席成员。

首版不保存长期点名历史；均衡轮选状态只保证当前点名会话内有效。

## 多屏规则

顶部课程表提供三种显示模式：

1. **指定屏幕**：使用稳定的显示设备标识保存选择；目标失效时依次尝试最近选择过且仍可用的屏幕，最后回退到 Windows 主屏幕。
2. **智能居中**：仅当显示器具有相同有效尺寸、排列成完整矩形网格且存在唯一的顶部中央屏幕时使用该屏幕；绝不跨越屏幕接缝。条件不成立时回退为复制模式。
3. **复制**：在每一块可用屏幕顶部创建一份当天课程表。

快捷启动器始终只有一个。它可以拖到任意屏幕，保存当前位置；屏幕断开、分辨率或 DPI 改变后自动修正到可见工作区。

## 课程表

### 循环模型

- 支持 1、2 或 3 周课表周期。
- 用户指定某个星期一作为周期起始周。
- 周期按自然周连续推进，节假日与停课日不暂停周期。
- 学校临时重排周期时，用户可以重新指定周期起始周。

### 节次

每个节次具有顺序、名称、开始时间和结束时间。节次数量与上下课时间由用户配置。

### 课程安排字段

- 课程名称：必填；
- 显示简称：可选；
- 颜色：可选；
- 任课教师：可选；
- 备注：可选，仅在主控面板显示；
- 课表周期位置、星期与节次：必填。

不保存教室和班级字段，因为当前安装已经代表固定教室与固定名单。

## 日历

### 法定日历

- 只包含中国大陆法定节假日和调休工作日参考数据。
- 应用内置当前学年涉及年份的数据；有网络时可更新年度数据包。
- 数据来源应追溯到国务院办公厅发布的年度通知。
- 更新法定日历数据不得覆盖教师已经修改的教学安排。

### 教学日历

教学日历才是学校实际采用的日期安排。具体日期可以标记为：

- 停课日；
- 正常教学日，采用当天星期对应的课表；
- 调课日，指定采用另一个星期几的课表。

法定日历只生成初始建议。调休工作日无法从国家通知推断应采用星期几的课表，必须由用户确认。

## 固定名单

- 一套安装只维护一份固定名单。
- 姓名必填，学号或座号可选，用于区分同名成员。
- 支持逐行新增、删除和修改。
- 支持从 Excel 复制后直接粘贴。
- 支持导入 `.xlsx` 和 `.csv`，不依赖目标电脑安装 Microsoft Excel。
- 不收集成绩、性别等与点名无关的信息。

## 数据归属

- 课程表、教学日历、法定日历缓存和固定名单属于教室，在同一电脑的 Windows 用户之间共享。
- 快捷启动器位置、显示屏选择、开机自启和其他界面偏好属于当前 Windows 用户。
- 首版不提供备份、云同步或跨电脑迁移。

## 联网与更新

- 核心功能不能依赖网络启动或运行。
- 联网仅用于检查软件版本和法定日历数据包。
- 软件版本只检查并提示，由用户主动下载和安装；上课期间不弹窗、不强制重启。
- 用户可以关闭软件更新检查。
- 法定日历数据可以静默下载，但必须通过完整性和签名校验后才可使用。
- 不上传课程表、名单、点名结果、使用统计、设备标识或用户标识。
- 不接入第三方分析或遥测 SDK。

## 可选开机自启

- 每个 Windows 用户独立选择是否自启。
- 安装后默认不开启。
- 自启时直接进入低干扰桌面状态，不自动打开主控面板。

## 明确不做

- Linux、macOS、Windows 7/8；
- 学生端、教师账号、登录与角色权限；
- 云同步、远程控制、Web 后台；
- 大学排课模型；
- 成绩或学生档案管理；
- 外部应用快捷启动；
- 自动安装软件更新；
- 首版数据备份与恢复；
- 遥测、广告和第三方分析。
