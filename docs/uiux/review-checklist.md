# ClassHelper UI/UX 审查清单

## 产品边界

- [ ] 界面没有课程表、节假日、教学日历或顶部桌面栏；
- [ ] 启动器只包含点名、名单、主控；
- [ ] ClassIsland 的职责不会在 ClassHelper 中重复配置。

## 核心流程

- [ ] 从启动器到首次点名结果不超过两次点击；
- [ ] 独立随机与均衡轮选的差异清楚；
- [ ] 空名单时有明确引导；
- [ ] 名单粘贴后先预览，保存状态清楚；
- [ ] 主控面板关闭后启动器仍可使用。

## 桌面体验

- [ ] 启动器可以拖动并吸边；
- [ ] 启动器不抢当前应用的键盘输入；
- [ ] 右键菜单可以退出；
- [ ] 开机自启默认关闭且可以随时取消。

## 视觉与可访问性

- [ ] 点名姓名在投影距离下清楚可读；
- [ ] 100%–200% DPI 下没有裁切；
- [ ] 键盘焦点可见；
- [ ] 状态不只依赖颜色；
- [ ] 动画短促且不会影响抽取结果。
