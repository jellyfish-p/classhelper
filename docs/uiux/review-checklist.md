# UI/UX 审查清单

预览图是视觉提案，审查时建议按以下顺序反馈。

## 1. 产品层级

- 顶部课程表是否足够安静，又能在桌面背景上看清？
- 快捷启动器是否容易发现，但不会遮挡课件？
- 主控面板是否像课堂工具，而不是企业后台？
- 点名窗口是否庄重、清楚，避免过度游戏化？

## 2. 视觉方向

- 暖灰纸张底色、靛蓝主色、青绿当前状态是否合适？
- 圆角、透明度与阴影是否过多或过少？
- 课程颜色是否容易区分且不过度鲜艳？
- 浅色和深色方案是否都需要进入首版？

## 3. 信息密度

- 顶部课程表需要显示哪些字段？
- 主控面板导航是否需要合并或拆分？
- 课程表编辑器的右侧检查器是否符合操作习惯？
- 日历中的标签和状态是否容易理解？

## 4. 操作流程

- 从桌面发起点名是否足够快？
- 课表修改是否需要支持更多批量能力？
- 调休工作日的“采用星期几课表”是否清楚？
- 名单导入预览是否包含足够的信息？

## 5. 建议反馈格式

按预览图文件名反馈即可：

```text
01-desktop-overview-v2：课程表再矮一点；启动器放右边。
03-timetable-editor：喜欢布局，但课程颜色需要更鲜明。
05-roll-call：姓名太大；希望加入手动重抽说明。
全局：主色改成偏青色。
```
