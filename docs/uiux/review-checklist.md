# ClassHelper UI/UX 审查清单

## 产品边界

- [ ] 界面没有课程表、节假日、教学日历或顶部桌面栏；
- [ ] 启动器只包含点名、名单、主控；
- [ ] ClassIsland 的职责不会在 ClassHelper 中重复配置。

## 核心流程

- [ ] 从启动器到首次点名结果不超过两次点击；
- [ ] 点名窗口无系统标题栏、左右栏与分割线，整块显示面均可触发抽取或拖动；
- [ ] 左侧中央的两个模式选项无间隙紧贴，平时收起为图标，悬停或点击聚焦时展开说明；
- [ ] 模式控件、刷新与退出均悬浮在抽取显示面上，刷新与退出并排位于右上角；
- [ ] 短按显示面触发抽取，超过系统拖动阈值后只移动窗口；
- [ ] 独立随机与均衡轮选的差异清楚；
- [ ] 空名单时有明确引导；
- [ ] 名单粘贴后先预览，保存状态清楚；
- [ ] XLSX/CSV 导入能识别非首行表头，并允许在预览中修正姓名、编号和参与状态列；
- [ ] 取消文件导入不会更改当前名单，确认导入后仍需显式保存；
- [ ] 主控面板关闭后启动器仍可使用。

## 桌面体验

- [ ] 启动器可以拖动并吸边；
- [ ] 启动器不抢当前应用的键盘输入；
- [ ] 右键菜单可以退出；
- [ ] 开机自启默认关闭且可以随时取消。

## 视觉与可访问性

- [ ] 全应用只使用钴蓝作为强调色，没有暖米色或紫色渐变；
- [ ] 按钮、输入框、卡片遵循统一圆角规则；
- [ ] 名单保存提供加载、成功和错误反馈；
- [ ] 点名姓名在投影距离下清楚可读；
- [ ] 100%–200% DPI 下没有裁切；
- [ ] 键盘焦点可见；
- [ ] 状态不只依赖颜色；
- [ ] 动画短促且不会影响抽取结果。
