# 课堂助手 UI/UX 设计规范

> 状态：已按 ClassIsland 分工更新
> 日期：2026-08-08
> 设计目标：两秒点名、安静常驻、远距离可读

## 1. 产品边界

ClassHelper 只有三层界面：

1. 置顶贴边启动器；
2. 固定名单与设置主控面板；
3. 随机点名结果窗口。

课程表、节假日、教学日历和顶部桌面栏由 ClassIsland 提供。ClassHelper 不显示课程状态，也不提供对应导航入口。

## 2. 视觉系统

设计参数：`DESIGN_VARIANCE 4 / MOTION 3 / VISUAL_DENSITY 5`。课堂环境优先可靠、清楚和可预测，不采用营销页式高动效。

- 冷灰背景 `#F3F5F8`，导航表面 `#E9EDF3`，内容表面 `#FFFFFF`；
- 主文字 `#121826`，次文字 `#5F6B7A`；
- 全应用只使用钴蓝 `#2F5BD3` 作为强调色，危险色为 `#C24154`；
- 中文使用 `Microsoft YaHei UI`；
- 正文 14 px，页面标题 24–26 px，点名姓名 56–72 px；
- 按钮使用 10 px、设置面板使用 14 px、主操作区使用 16 px 圆角；
- 避免暖米色、等宽卡片墙、饱和渐变、炫光玻璃和循环动画。

## 3. 快捷启动器

- 始终置顶，不进入任务栏；
- 默认 64 px 宽的竖向胶囊；
- 顶部 24 px 是拖动把手；
- 松开鼠标后吸附最近屏幕边缘；
- 入口顺序固定为点名、名单、主控；
- 右键菜单提供打开主控与退出；
- 不包含课程、日历或日期组件。

目标：从任意桌面状态到首次点名结果最多两次点击。

## 4. 主控面板

导航只包含：

- 总览；
- 随机点名；
- 固定名单；
- 启动设置；
- 关于。

总览展示固定名单人数、默认点名方式和开始点名按钮。不得制造统计图、完成率或课程占位卡片。

### 固定名单

- 列项：姓名、学号/座号、是否参与点名；
- 姓名必填，其余可选；
- 支持新增成员和粘贴文本预览；
- 保存前保留用户编辑，保存失败不得清空；
- 后续文件导入必须先预览再应用。

### 随机点名设置

- 独立随机：明确说明可能连续抽到同一人；
- 均衡轮选：明确说明一轮内不重复；
- 使用两张说明卡，不使用“真随机/伪随机”技术术语。

### 启动设置

- 说明启动器可以拖动和吸边；
- 提供当前 Windows 用户的开机自启开关；
- 不包含顶部栏、多屏课程模式或 ClassIsland 设置。

## 5. 点名窗口

- 默认 900 × 540 px，居中置顶，使用无系统标题栏的圆角窗口；
- 左侧纵向排列独立随机与均衡轮选，并在底部显示候选/剩余人数；
- 刷新和退出使用右上角图标按钮；
- 中央区域显示姓名，学号或座号作为次级信息；
- 点击中央任意空白区域直接抽取下一位；
- 抽取结果先确定，再播放 320–650 ms 的淡入动画；
- 不使用老虎机滚动、彩屑或长时间悬念动画。

## 6. 状态与无障碍

- 空名单时关闭抽取按钮，并引导用户进入固定名单；
- 本地保存失败时保留编辑内容；
- 所有操作有键盘路径和可见焦点；
- 正文对比度不低于 4.5:1；
- 状态不能只依赖颜色；
- 支持 100%–200% DPI；
- 减少动态效果时直接显示抽取结果。

## 7. 工程约束

- XAML 视觉 token 统一放入 ResourceDictionary；
- 点名策略不进入 View 或 ViewModel；
- 启动器吸边保持纯算法可测试；
- 页面必须实现空、错误和正常状态；
- 历史 Imagine 图片包含已移除的课程功能，仅作为早期设计档案，不能作为当前实现依据。
