# 课堂助手 UI/UX 设计规范

> 状态：待产品审查
> 日期：2026-08-08
> 设计目标：安静常驻、两秒可用、投影可读

## 1. 设计方向

课堂助手不是一套“教学管理后台”，而是教室电脑上的三层工具：

1. **环境层**：顶部课程表，像桌面信息牌一样存在，不主动争夺注意力；
2. **快捷层**：置顶吸边启动器，任何时候都能一击进入核心功能；
3. **专注层**：主控面板和点名窗口，只在教师明确操作时出现。

视觉关键词：**安静、清楚、可信、略带纸张温度**。避免游戏化、炫光玻璃、饱和渐变、密集卡片和后台系统式表格堆砌。

### 核心原则

- **课上少打扰**：常驻界面不抢焦点、不播放循环动画、不弹出更新窗口。
- **远距离可读**：顶部课程和点名结果按投影距离设计，不依赖小图标表达关键状态。
- **状态先于装饰**：当前课、下一节、停课和待确认调课拥有稳定的视觉语义。
- **危险操作明确**：删除名单、覆盖导入和放弃课表修改必须二次确认。
- **完整功能只进主控**：环境层和快捷层不承担复杂编辑。

## 2. 视觉系统

### 2.1 色彩

| Token | Light | Dark | 用途 |
|---|---:|---:|---|
| `Canvas` | `#F3F1EC` | `#11151B` | 主控面板背景 |
| `Surface` | `#FBFAF7` | `#1A2029` | 内容表面 |
| `SurfaceRaised` | `#FFFFFF` | `#222A35` | 浮层、启动器 |
| `TextPrimary` | `#18212B` | `#F1F4F7` | 主文字 |
| `TextSecondary` | `#66717F` | `#A8B1BD` | 说明文字 |
| `Border` | `#DCE1E6` | `#343D49` | 分隔和描边 |
| `Brand` | `#425FC7` | `#8EA6FF` | 主操作、选中状态 |
| `Current` | `#267F73` | `#5EC9B7` | 当前课程、成功 |
| `Next` | `#C47A20` | `#F0B35F` | 下一节、待处理 |
| `Danger` | `#BE4D5B` | `#FF8995` | 删除、错误 |

课程颜色从一套低饱和色板中选择：靛蓝、青绿、琥珀、紫灰、砖红、湖蓝。颜色只用于识别课程，不承载唯一信息；课程名称始终可见。

透明表面必须保留至少 84% 的不透明视觉底色。桌面背景复杂时自动增加遮罩，禁止为了“透明感”牺牲可读性。

### 2.2 字体

- 中文：`Microsoft YaHei UI`；
- 英文与数字：`Segoe UI Variable`，不可用时跟随系统字体；
- 点名结果：56–72 px，Semibold；
- 顶部当前课程：18–20 px，Semibold；
- 页面标题：24 px，Semibold；
- 正文：14 px；
- 辅助文字：12 px，最低不得小于 12 px。

时间数字使用 tabular figures，避免倒计时和时间变化时布局抖动。

### 2.3 空间与形状

- 基础网格：4 px；常用间距：8 / 12 / 16 / 24 / 32 px；
- 控件高度：普通 36 px，主要按钮 40 px，触控友好操作 44 px；
- 主控面板圆角：12 px；课程 chip：8 px；启动器：18 px；
- 描边：1 px；阴影只用于悬浮层，不给每张卡片加阴影；
- 内容最大宽度：主控面板内 1160 px。

### 2.4 图标

使用统一的 Fluent 风格线性图标，默认 20 px、1.75 px 视觉线宽。关键按钮必须同时具备文字或 tooltip。禁止混用彩色 emoji、填充图标和不同线宽图标。

### 2.5 动效

| 场景 | 时长 | 曲线 |
|---|---:|---|
| hover / pressed | 90–120 ms | ease-out |
| 启动器展开、吸边 | 160–200 ms | cubic ease-out |
| 面板切换 | 180 ms | opacity + 4 px 位移 |
| 点名揭晓 | 500–650 ms | 减速，不循环 |

不使用弹簧、抖动、彩屑和老虎机式长动画。启用“减少动态效果”后，点名直接淡入结果。

## 3. 窗口体系

### 3.1 顶部课程表 Banner

**层级**：桌面底层；不交互、不激活、不进任务栏或 Alt+Tab。
**尺寸**：距顶部 12 px，高 76–88 px，宽度为屏幕工作区的 92%，最大 1540 px。
**布局**：

- 左侧 156 px：日期、星期、周期位置；
- 中间：当天全部节次，等宽自适应；
- 右侧 112 px：当前时间与教学日历状态。

课程状态：

- 已结束：降低对比度，不加删除线；
- 当前课程：青绿色实底，显示“进行中”和结束时间；
- 下一节：琥珀色细描边，显示开始时间；
- 后续课程：中性表面；
- 空节次：显示“空课”，使用点状弱边框；
- 停课日：不渲染空课表，改为居中的“今日停课”信息；
- 调课日：日期区显示“采用周三课表”等明确说明。

窄屏时减少日期区宽度并压缩课程间距；不隐藏当天节次。课程超过 10 节时允许 Banner 增高为两行，但不得使用横向滚动。

### 3.2 快捷启动器 Launcher

**层级**：始终置顶；不抢键盘焦点。
**默认形态**：56 px 宽的竖向胶囊，吸附屏幕左/右边缘；吸附上/下边缘时变为横向。
**入口顺序**：

1. 今日课程；
2. 教学日历；
3. 随机点名（主操作，使用 Brand 色）；
4. 主控面板。

启动器顶部或左端保留 20 px 拖动把手。拖动跨过屏幕边界时展示目标屏幕吸附预览；释放后以 180 ms 吸附。右键菜单提供：锁定位置、隐藏 30 分钟、打开主控面板、退出课堂助手。

隐藏 30 分钟后，在屏幕边缘保留 3 px 唤回热区；到时自动恢复。该行为不改变开机自启设置。

### 3.3 主控面板

**默认尺寸**：1180 × 760 px；最小 1024 × 680 px；普通可调整窗口。
**结构**：

- 左侧 196 px 导航栏；
- 顶部 64 px 页面标题与状态操作；
- 主内容区使用 24 px 外边距；
- 复杂编辑页允许右侧 300 px 检查器。

导航：

- 总览
- 课程表
- 教学日历
- 随机点名
- 固定名单
- 显示与启动
- 更新与关于

不单独设置“设置”总入口，设置应落在对应对象附近。

### 3.4 点名窗口

**尺寸**：960 × 560 px，居中于启动器所在屏幕；普通置顶窗口。
**区域**：

- 顶栏：模式、候选人数、退出；
- 主舞台：结果姓名和可选学号/座号；
- 底栏：再抽一位、临时排除、结束点名。

抽取前展示一句明确提示，例如“均衡轮选 · 本轮剩余 31 人”。抽取后先呈现姓名，随后淡入学号/座号，避免信息同时跳出。

## 4. 信息架构与页面

### 4.1 首次启动向导

只在没有共享课堂数据时出现，共四步：

1. **欢迎**：说明数据仅保存在本机；
2. **课表周期**：选择 1/2/3 周并设置周期起始周；
3. **节次时间**：从中小学常见模板开始，允许增删调整；
4. **固定名单**：粘贴或导入，也可明确选择“稍后设置”。

完成后直接展示桌面 Banner 和 Launcher。不要在向导中要求完成整张课表；主控面板提供显眼的“继续完善课程表”。

### 4.2 总览

总览不是卡片墙，采用一条主时间轴与两个辅助区域：

- 顶部：今日课程时间轴，与桌面 Banner 同源；
- 左下：教学日历提醒，例如“周六需指定采用哪天课表”；
- 右下：固定名单人数、点名默认模式、显示屏状态；
- 页面右上：`开始点名` 主按钮。

没有待处理事项时显示安静的“教学日历已就绪”，不制造虚假的完成率或统计图。

### 4.3 课程表编辑器

顶部工具条：

- 周期段选择：第 1 周 / 第 2 周 / 第 3 周；
- `复制上一周`；
- `清空本周`（危险操作）；
- `保存更改`。

主体是星期列 × 节次行网格。点击单元格后打开右侧检查器：

- 选择已有课程或新建课程；
- 编辑课程名称、简称、颜色、任课教师和备注；
- 删除本次课程安排。

拖动课程 chip 可以移动；按住 Ctrl 拖动可以复制。键盘用户可用方向键移动焦点，Enter 编辑，Delete 删除。出现冲突或节次时间重叠时，保存按钮禁用并在网格就地标错。

复杂编辑采用显式保存。离开页面时若有未保存修改，弹出“保存并离开 / 放弃修改 / 继续编辑”。

### 4.4 教学日历

主体为月历，右侧为选中日期检查器。日期视觉：

- 普通教学日：无额外填色；
- 法定放假建议：淡红背景 + `法定` 标签；
- 调休工作日：淡琥珀背景 + `待确认` 标签；
- 教师停课：实心红点；
- 教师调课：Brand 色角标并显示来源星期；
- 教师设为正常教学：青绿色对勾。

右侧检查器只提供三种清晰选择：停课、正常教学、调课。选择调课后必须指定采用星期几。教师手动设置区显示“优先于法定日历建议”。

批量操作放在月历上方：设置日期范围、接受本月法定建议、清除教师设置。批量操作必须先预览影响日期。

### 4.5 固定名单

列表列项：序号、姓名、学号/座号、状态、操作。首版不显示成绩、性别或头像。

主要操作：

- `粘贴名单`：读取剪贴板并进入导入预览；
- `导入文件`：选择 XLSX/CSV；
- `新增成员`；
- `移除所选`。

导入预览必须显示识别到的姓名列、将新增/更新/忽略的人数和前 20 行示例。无法确定姓名列时要求用户映射，不进行模糊猜测。覆盖现有名单前明确说明会影响当前点名会话。

### 4.6 随机点名设置

设置页只解释两种模式：

- **独立随机**：每次从完整名单抽取，可能连续抽到同一人；
- **均衡轮选**：一轮内不重复，全部点过后开始新一轮。

使用双卡单选而不是技术术语下拉框。默认模式保存到当前 Windows 用户偏好。下方提供 `打开点名窗口`，用于课前试用。

### 4.7 显示与启动

顶部使用简化的显示器拓扑图，与 Windows 当前排列一致。顶部课程表模式为三张单选卡：

- 指定屏幕；
- 智能居中；
- 每屏复制。

指定屏幕模式显示回退顺序；智能居中条件不成立时直接解释为何回退为复制。下方提供 Launcher 位置预览、锁定位置、恢复默认位置和开机自启开关。

所有显示设置即时预览、自动保存，并提供 10 秒 `撤销` toast，避免额外的全局保存按钮。

### 4.8 更新与关于

- 当前版本和最后检查时间；
- 检查软件更新开关；
- `立即检查`；
- 法定日历数据年份、来源与更新时间；
- 本地数据位置；
- 隐私说明：不上传课程表、名单和使用统计。

有软件更新时只显示 `查看新版本`，不在应用内静默安装。

## 5. 关键流程

### 编辑课程

`Launcher → 主控面板 → 课程表 → 选择周期周 → 单元格 → 右侧检查器 → 保存更改`

目标：修改一节课程不超过 5 次点击；已有课程可以复用，不重复录入名称和颜色。

### 处理调休工作日

`总览提醒 → 教学日历选中日期 → 调课 → 选择采用星期几 → 保存`

目标：任何“待确认”状态都说明缺少什么，不使用只有颜色没有文字的警告。

### 发起点名

`Launcher 点名按钮 → 选择/沿用模式 → 开始 → 显示结果 → 再抽一位或结束`

目标：从桌面到首次结果最多 2 次点击。点名窗口记住上一次模式，但顶栏始终显示当前模式。

### 调整显示屏

`主控面板 → 显示与启动 → 选择模式 → 即时预览 → 自动保存`

目标：窗口不得因屏幕拔插落到不可见区域；回退发生时给出一次非阻塞 toast。

## 6. 状态设计

### 空状态

- 无课程表：`还没有课程安排` + `开始设置课程表`；
- 无名单：`固定名单为空` + `粘贴名单` / `导入文件`；
- 无网络：继续展示本地内容，只在更新页显示 `暂时无法检查更新`；
- 无待处理日历：`教学日历已就绪`，不展示空白警告框。

### 加载状态

本地读取超过 150 ms 才出现 skeleton，避免闪烁。网络检查不占用整页 loading；按钮内显示进度并允许取消。

### 错误状态

- 可恢复错误使用页内说明和明确下一步；
- 保存失败保留用户编辑内容；
- 数据库不可写时停止编辑并说明共享目录权限问题；
- 导入失败显示文件级原因，不输出技术堆栈；
- 日志详情放入可复制的“诊断信息”，不得包含学生信息。

### Toast

用于设置已保存、窗口已回退、法定日历已更新等非阻塞反馈。默认 4 秒；包含撤销时 10 秒。错误和必须决策的事情不能只靠 toast。

## 7. 可访问性

- 支持 100%–200% DPI，不以固定像素裁切文字；
- 所有操作具备键盘路径和可见焦点环；
- 正文和背景对比度不低于 4.5:1，大字不低于 3:1；
- 状态不只依赖颜色，配合文字、图标或形状；
- 支持 Windows 高对比度和减少动态效果；
- 课程 Banner 在投影复制模式下仍使用实际屏幕 DPI 渲染；
- 屏幕阅读器名称使用真实业务词语，例如“采用星期三课表”，不使用“按钮 3”。

## 8. 文案规则

- 使用“课程表、教学日历、固定名单、独立随机、均衡轮选”等已确认词汇；
- 避免“真随机、伪随机、账户、班级库、日程事件”；
- 按钮写动作：`保存更改`、`开始点名`、`采用星期三课表`；
- 危险操作说明结果：`清空第 2 周课程`，不写模糊的`确定`；
- 时间统一为 24 小时制；日期默认 `8 月 8 日 周六`，设置与来源处使用完整日期。

## 9. 工程交付要求

- XAML 视觉 token 统一放入 ResourceDictionary，不在 View 中散落颜色和尺寸；
- ViewModel 只提供页面状态与命令，课程计算和点名策略留在深模块；
- Banner、Launcher、主控面板和点名窗口分别拥有窗口样式资源；
- 页面必须实现空、加载、错误、只读和正常状态；
- 高保真预览图用于审查视觉方向，不是像素级实现依据；文字和行为以本规范为准。
