# 0.1 Preview 实现说明

## 本版目标

这一版验证教室电脑上的最短点名闭环：应用启动后提供贴边启动器和主控面板；教师维护一份固定名单后，可以从桌面两次点击内得到点名结果。

课程表、节假日、教学日历和顶部桌面栏已经移出项目，由 ClassIsland 承担。ClassHelper 专注于名单和点名，不与 ClassIsland 交换数据。

## 已实现

- `.NET 10 + WPF` 解决方案，核心逻辑不引用 WPF；
- 主控面板：总览、随机点名、固定名单、启动设置、关于；
- 固定名单：姓名必填，学号/座号可选，可暂停参与点名；
- 文本名单导入预览：支持每行姓名，以及“姓名 + 逗号/制表符 + 编号”；
- 文件名单导入预览：支持 XLSX/CSV、智能表头与列识别，并可在确认前修正映射；
- 独立随机：每次从完整启用名单抽取；
- 均衡轮选：一轮内不重复，耗尽后自动开始下一轮；
- 点名会话可切换模式和重置本轮；
- 快捷启动器可拖动，并吸附主屏幕工作区最近边缘；
- 每用户开机自启；
- JSON 数据以临时文件写入后原子替换；
- `--smoke-test` 检查 WPF XAML 能否加载；
- 点名策略和吸边算法共 8 个自动测试。

## 当前限制

- 吸边只按主屏工作区定位，尚未处理多屏与混合 DPI；
- 预览数据存于当前用户目录，尚未迁移到整机共享 SQLite；
- 没有 XLSX/CSV 文件选择器、软件更新和 MSI；
- 开发构建开启自启时会记录当前开发输出路径，安装版需改为安装目录路径。

## 工程结构

```text
src/ClassHelper.Core
  Display/       吸边纯算法
  RollCall/      固定名单模型、两种点名策略与随机源

src/ClassHelper.App
  MainWindow     主控面板
  LauncherWindow 贴边启动器
  RollCallWindow 点名结果窗口
  Services/      生命周期、本地保存、自启
  ViewModels/    UI 状态和数据适配

tests/ClassHelper.Core.Tests
  RollCall/      抽取行为测试
  Display/       吸边行为测试
```

## 下一版建议

先对主控、启动器和点名窗口做 Windows 10/11、多 DPI 人工验收，再进入 SQLite 共享数据和安装器。课程显示继续交由 ClassIsland，不在后续计划中重复建设。
